# AI旅游定制助手

一个基于Vue3 + Element Plus的智能旅游定制Web应用，遵循Trea设计规范，提供AI生成旅游攻略、景点/酒店/机票推荐、行程管理、智能问答等功能。

## 项目信息

- **项目名称**：AI旅游定制助手
- **核心功能**：
  - AI生成旅游攻略
  - 景点/酒店/机票推荐
  - 行程管理
  - 智能问答
  - 预订辅助
- **技术栈**：
  - Vue3 + Vite + TypeScript
  - Element Plus
  - Trea设计风格
- **主色调**：天蓝色 #1677FF 旅行蓝
- **辅助色**：暖橙色 #FF7D00
- **风格要求**：简约、干净、卡片式布局、柔和阴影、留白充足、旅行氛围感

## 页面结构

1. **首页**：Banner + 快捷攻略生成 + 热门推荐 + 导航
2. **AI攻略定制页**：表单填写目的地、天数、预算、出行类型
3. **攻略结果页**：展示AI生成的详细行程
4. **智能问答页**：AI聊天对话界面
5. **用户中心**：个人信息、收藏、历史行程

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 设计规范

### Trea设计语言

- **间距**：8px倍数
- **圆角**：8px
- **字体层级**：清晰的字体大小和权重区分
- **按钮质感**：柔和的阴影和过渡效果
- **色彩系统**：
  - 主色：#1677FF（天蓝色）
  - 辅助色：#FF7D00（暖橙色）
  - 中性色：多级灰色调

### 交互设计

- **hover动效**：柔和的过渡效果
- **表单验证**：实时验证和错误提示
- **加载状态**：明确的加载指示器
- **流式打字效果**：AI回复时的打字动画

## 功能特点

1. **智能攻略生成**：根据用户输入的目的地、天数、预算等信息，AI自动生成个性化的旅游攻略
2. **实时问答**：智能问答系统，随时解答用户的旅行问题
3. **行程管理**：用户可以查看和管理自己的历史行程和收藏
4. **响应式设计**：适配PC端和移动端
5. **现代UI**：遵循Trea设计规范，提供美观、易用的界面

## 技术亮点

- **Vue3 Composition API**：使用最新的Vue3语法，代码结构清晰
- **TypeScript**：提供类型安全，减少开发错误
- **Element Plus**：丰富的UI组件，加速开发
- **Vite**：快速的构建工具，提升开发体验
- **响应式设计**：适配不同屏幕尺寸
